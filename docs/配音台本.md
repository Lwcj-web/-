# FinGuard 演示视频 · 配音台本

> 这份台本给「自己配音」用。台词与 `tools/video/script.js` 完全同源，改台词请改那个文件，再跑 `node tools/video/scriptbook.js` 重新生成本台本。

## 怎么录

**1. 按镜头分段录，一段一个文件。** 命名 `S1.wav` … `S10.wav`，放在 `media/vo/` 下。
片头 S0 和片尾 S10 没有旁白，不用录。所以实际要录 **9 段**。

**2. 每句之间停 0.3–0.5 秒。** 不要连读。这个停顿是剪辑点，停得太短我没法把句子切开对齐画面。
每段开头也留半秒静音。

**3. 念错就整段重录，不要拼接。** 拼接的地方音量和对不上，剪出来很假。

**4. 语速参考 4.2 字/秒**，比平时说话略慢一点。整片旁白约 3 分 02 秒，加上片头片尾约 3 分 18 秒，赛制上限 5 分钟。

## 录完之后

把 `S1.wav` … `S9.wav` 放进 `media/vo/`，告诉我「录好了」，我会做三件事：

1. 用静音检测找出每句话的真实边界，和台本逐句对齐（对不上会报出来，不会硬套）
2. 按你的实际语速重算时间轴，重排字幕
3. 重新渲染画面并混音，出新的 `FinGuard-演示视频.mp4`

画面不用重录，截图和运镜都会按新时长自动重算。
